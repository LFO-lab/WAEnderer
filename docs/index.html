WÆnderer Projecting and Navigating Personal Sound Corpora in Pre-Trained Audio Models

WÆnderer is a Python tool for exploring personal collections of sounds in real time. It maps a sound collection into a navigable space, allowing musicians to move through, combine, and reorganize their own material using a pre-trained audio model.
