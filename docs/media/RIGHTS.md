# Demo media rights ledger

No demo media is approved for public distribution until every required field
below is complete. Repository licensing does not automatically cover recordings,
source corpora, performances, images, or videos.

## Approval states

- `draft`: not cleared; do not publish.
- `permission-recorded`: written permissions are stored by the project team.
- `approved`: all rights and attribution fields are complete; publication is allowed.
- `withdrawn`: remove from public distribution.
